    02 ОСНОВА

    HTML: від набору цифр до структури

    Семантичні теги роблять дані зрозумілими не лише людині, а й браузеру та допоміжним технологіям. Розмітка описує логічні блоки панелі — незалежно від їхнього зовнішнього вигляду.

    Анатомія аналітичної сторінки

    Одна сторінка = декілька вкладених смислових блоків.

    <main> Основний вміст
    <section> Дашборд
    <article> Показник KPI
    <article> Графік
    <table> Дані звітів
    <section> Навчальні пояснення
    Навіщо це аналітику? Зрозуміла структура, пошук, доступність, підтримка та простіше підключення даних.
    SEMANTIC.HTML
    <main>
  <section aria-labelledby="status-title">
    <h2 id="status-title">Стан забезпечення</h2>
    <article class="kpi">
      <h3>Виконання плану</h3>
      <output>84%</output>
      <progress value="84" max="100">84%</progress>
    </article>
  </section>
</main>

    Теги <section> і <article> позначають незалежні частини; <output> — результат обчислення; <progress> — міру виконання завдання.

    03 КОМПОНУВАННЯ

    Flexbox чи Grid? Спробуйте обидва

    Flexbox розподіляє елементи в одному напрямку (рядок або колонка). CSS Grid задає сітку рядків і стовпців. Обидва способи можна поєднувати в одному дашборді.

    Інтерактивна схема компонування

    Змінюйте спосіб розташування одного й того самого HTML.

    01KPIПоказник
    02BARДіаграма
    03FEEDПодії
    04DATAТаблиця
    .dashboard {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 16px;
}
    Grid — двовимірна система.

    Зручний для карток KPI, панелей аналітики та симетричних розкладок. Властивість gap задає проміжки між елементами.

    display: flex

    Рядки інструментів

    Фільтри, заголовок із кнопками, навігація, вирівнювання елементів.

    display: grid

    Сітка дашборду

    Картки, графіки, таблиці, панелі різної ширини.

    minmax() + auto-fit

    Автоматична адаптація

    Кількість стовпців змінюється залежно від доступної ширини.

    Для простих аналітичних завдань достатньо стандартних елементів HTML, псевдоелементів і фонових градієнтів. Нижче — три прийоми з прикладами коду.

    Кільцева діаграма

    05 РОБОТА З ДАНИМИ

    Аналітична таблиця як інструмент

    HTML-таблиця забезпечує природні заголовки колонок і доступність. CSS додає читабельність, індикатори та стани; JavaScript — пошук, фільтрацію, сортування й експорт.

    КЛЮЧОВІ ПРИЙОМИ

    Структура + оформлення

    <thead>, <tbody>, <th scope="col"> — структура даних. position: sticky, :hover, overflow-x: auto — читабельність і адаптивність.

    .table-scroll { overflow-x: auto; }
th { position: sticky; top: 0; }
tbody tr:hover { background: #24343b; }

    08 ІНТЕРФЕЙС ДЛЯ РІЗНИХ ЕКРАНІВ

    Адаптивність, доступність, друк

    Військовий аналітик може переглядати звіт на великому моніторі, ноутбуку чи телефоні. CSS медіазапити та контейнерні запити змінюють компонування без дублювання HTML.

    Перевірте доступність

    • Смислові <h1>…<h3> і заголовки таблиць
    • Фокус клавіатури і підписи кнопок
    • Значення не передаються лише кольором
    • Контраст, читабельні числа та масштаб
    • prefers-reduced-motion і стилі друку
    09 ПІДСУМОК

    Від прототипу до власної панелі

    HTML і CSS — не лише оформлення вебсайту. Це практичні інструменти подання даних для інформаційно-аналітичної діяльності.

    ПРАКТИЧНЕ ЗАВДАННЯ · 20–30 ХВ

    Створіть свій мінідашборд

    На основі цього проєкту зробіть екран аналітика з 4 KPI, таблицею, гістограмою та статусними індикаторами. Оберіть нейтральну предметну область: документообіг, облік ресурсів або інформаційні потоки.

    1. Замініть умовні дані в app.js.
    2. Налаштуйте палітру та сітку в styles.css.
    3. Додайте один новий HTML-компонент.
    4. Перевірте мобільну версію та клавіатурну навігацію.
