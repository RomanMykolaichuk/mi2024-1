# DATA/VIS LAB — HTML + CSS для візуалізації військової аналітики

Автономна інтерактивна вебсторінка українською мовою. Навчальний прототип демонструє **можливості нативного HTML5, CSS3 і невеликого обсягу vanilla JavaScript** для побудови аналітичного інтерфейсу.

## Як запустити

1. Розпакуйте ZIP-архів, не змінюючи структуру папки.
2. Відкрийте **`index.html`** у Chrome, Firefox або Edge. Достатньо подвійного натискання — **сервер не потрібен**.
3. Перемикайте сценарії на дашборді, фільтруйте таблицю та змінюйте CSS у практичній лабораторії.

У застосунку **немає мережевих запитів, CDN, npm-залежностей, фреймворків, аналітичних трекерів або серверної частини**. CSV експортується безпосередньо в браузері. Кнопка «Друк / PDF» використовує стандартний діалог друку браузера.

## Структура проєкту

```text
military_html_css_lab/
├── index.html       Семантична HTML-структура всіх прикладів
├── styles.css       Усі компоненти, CSS Grid, Flexbox, графіки, адаптивність

└── preview.png      Знімок сторінки (за наявності)
```

## Що демонструє

| Розділ | Технології | Практичне призначення |
|---|---|---|
| 01. Живий дашборд | HTML, CSS Grid, CSS custom properties, JS | KPI, тенденції, структура, сектори, журнал |
| 02. Семантика | `main`, `section`, `article`, `output`, `progress` | Структура й доступність |
| 03. Компонування | Flexbox, Grid, `gap`, `minmax` | Сітки аналітичних блоків |
| 04. Графіки CSS | `height`, `conic-gradient`, progress bars | Стовпчики, кільця, шкали |
| 05. Таблиці | HTML `table`, пошук, фільтр, сортування, CSV | Журнал аналітичних записів |
| 06. Теплова карта | Grid, кольорові класи, псевдоелементи | Умовні агреговані сектори й хронологія |
| 07. CSS-лабораторія | CSS variables, `input type=range` | Практичний підбір параметрів інтерфейсу |
| 08. Адаптивність | Media/container queries, focus, print | Робота з монітором, планшетом, телефоном |
| 09. Практичне завдання | Повторне використання коду | Власний простий аналітичний дашборд |

## Що можна змінити

- **Зміст і тексти:** `index.html`.
- **Палітра, відступи, сітка, типографіка:** початок `styles.css` (`:root`).
- **Сценарії і динамічні показники:** об'єкт `scenarioData` на початку `app.js`.
- **Таблиця:** масив `records` у `app.js`.
- **Нові компоненти:** додайте HTML-елемент і CSS-клас, а JS — лише для реакції на події.

## Методика заняття на 90 хвилин

- 0–10 хв: постановка аналітичного завдання, демонстрація повного дашборду.
- 10–25 хв: роль HTML, семантика і дерево сторінки.
- 25–40 хв: порівняння Flexbox і Grid.
- 40–55 хв: CSS-графіки — висота, градієнти, індикатори.
- 55–70 хв: таблиці, теплові карти, часові осі.
- 70–85 хв: лабораторія CSS, адаптивна верстка.
- 85–90 хв: постановка практичного завдання.

## Важливі обмеження

**Усі дані є виключно синтетичними навчальними прикладами.** У застосунку немає реальних донесень, географічних координат, позицій, маршрутів, персональних даних або оперативних відомостей. Схема секторів — абстрактна матриця, не географічна карта.

CSS-графіки корисні для простого прототипування та навчання. Для справжніх географічних карт, великих часових рядів, складних інтерактивних графів і статистичних візуалізацій доцільніше використовувати SVG/Canvas, спеціалізовані бібліотеки й повноцінні джерела даних. У реальних системах окремо необхідні валідація, контроль доступу, логування, управління даними й безпека.

## Сумісність

Сучасні Chrome / Edge / Firefox. Для демонстрації контейнерних запитів потрібен браузер, який підтримує `@container`. Інші розділи не залежать від цієї можливості. Передбачені стилі друку, видимий фокус клавіатури та `prefers-reduced-motion`.
