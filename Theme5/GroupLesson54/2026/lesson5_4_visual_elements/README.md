# Тема 5. Заняття 4 — Підбір візуальних елементів

Інтерактивна навчальна сторінка українською мовою для практичного порівняння графіків **Chart.js** та картографічного редактора **milsymbol + Leaflet + OpenStreetMap**.

## Як запустити

1. Розпакуйте архів, не порушуючи структуру папок.
2. Відкрийте `index.html` у Chrome, Firefox або Safari. Зазвичай додаткове встановлення не потрібне.
3. Якщо браузер блокує функції локальних файлів, запустіть у цій папці локальний вебсервер командою `python -m http.server 8000`, потім перейдіть на `http://localhost:8000/`.

**Увага:** бібліотеки Chart.js, Leaflet і milsymbol підвантажуються з CDN, а картографічні підкладки — із сервера OpenStreetMap. **Для повноцінної роботи необхідний Інтернет.** Локальний сервер надає файли, але не замінює інтернет-з'єднання. При розгортанні для великої аудиторії рекомендується розмістити JS/CSS бібліотеки локально, а для підкладки вибрати сервіс карт, розрахований на таке навантаження.

## Вкладка 1 — Chart.js

- Чотири умовні набори даних військової аналітики.
- Шість способів візуалізації: bar, line, doughnut, pie, radar, scatter.
- Налаштування легенди, осей, stacked, ручне редагування даних.
- Пояснення, де обраний тип діаграми доречний.
- Показ JS-коду та експорт PNG.

Формат даних у редакторі: `категорія; значення_1; значення_2`. Приклад:

```text
Пн; 12; 15
Вт; 16; 18
Ср; 15; 17
```

Друга серія необов’язкова, але якщо вона є — значення потрібно вказати для кожної категорії.

## Вкладка 2 — milsymbol + OpenStreetMap

- Конструктор умовного знака: тип об'єкта, належність, рівень, розмір, SIDC.
- Наочний SVG-прев’ю знака, літерний SIDC з 15 символів, підтримка ручних 20/30-значних числових кодів.
- Кнопка `Розмістити знак на карті` увімкне режим додавання: клацайте потрібні точки.
- Для редагування виберіть об'єкт на карті або зі списку; задайте нові параметри та натисніть `Оновити вибраний об'єкт`.
- Знаки можна переміщувати перетягуванням.
- Сценарій з трьома **вигаданими навчальними** об’єктами та експорт/імпорт GeoJSON (координати у порядку `[довгота, широта]`).
- Об'єкти автоматично зберігаються у `localStorage` поточного браузера.

**Це демонстраційний редактор, не сертифікована військова ГІС.** Набір типів обмежений навчальними прикладами; результати потрібно верифікувати за чинними стандартами та відомчими правилами умовних знаків. Не вводьте реальні оперативні координати чи чутливі дані: карта використовує сторонній сервіс тайлів. Під час роботи з реальними даними використовуйте дозволені захищені інформаційні системи та внутрішні картографічні ресурси.

## Програмні компоненти

- Chart.js 4.5.1 — https://www.chartjs.org/docs/latest/
- Leaflet 1.9.4 — https://leafletjs.com/reference.html
- milsymbol 3.0.4 — https://github.com/spatialillusions/milsymbol
- OpenStreetMap tile policy — https://operations.osmfoundation.org/policies/tiles/

Інтерфейс створений на **HTML + CSS + Vanilla JavaScript** без React, збірки та бекенду. Зразки даних вигадані.
