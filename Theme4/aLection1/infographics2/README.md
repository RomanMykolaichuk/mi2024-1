# infographics2 — Theme 4.1 visual lecture

Новий комплект із 10 фотореалістичних інфографік для лекції 4.1 **«Огляд сучасних методів аналізу даних в інтересах ІАЗ ОУВ»**.

## Порядок використання

1. `01_theme4_methods.jpg` — Тема 4. Методи аналізу даних в інтересах ІАЗ ОУВ.
2. `02_theme4_logic.jpg` — логіка Теми 4 за структурою курсу / репозиторію.
3. `03_methods_classification.jpg` — класифікація сучасних методів аналізу даних.
4. `04_statistical_methods.jpg` — статистичні методи аналізу.
5. `05_time_series_forecasting.jpg` — часові ряди та прогнозування.
6. `06_geospatial_fusion.jpg` — геопросторовий аналіз та multi-sensor fusion.
7. `07_clustering_anomaly_network.jpg` — кластеризація, виявлення аномалій та мережевий аналіз.
8. `08_deep_learning_cv.jpg` — Deep Learning та Computer Vision.
9. `09_nlp_llm_rag.jpg` — NLP, LLM та RAG для аналізу текстів.
10. `10_future_ai_methods.jpg` — перспективні методи ШІ: Multimodal AI, XAI, RL та Human-in-the-Loop.

## Логіка комплекту

`місце Теми 4 → логіка курсу → taxonomy → класичні та спеціалізовані методи → сучасні AI-методи → перспективні AI-підходи`

Інтерактивна сторінка `interactive/lessons/theme4.html?lesson=t4-l1` використовує цей комплект як основну **Visual Lecture** перед інтерактивною вправою Method Selector.
