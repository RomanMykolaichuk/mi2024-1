# infographics2 — Theme 4.1 visual lecture

Комплект із 10 інфографік для заняття 4.1 **«Огляд сучасних методів аналізу даних в інтересах ІАЗ ОУВ»**.

## Порядок використання

1. `01_theme4_methods.png` — місце Теми 4 та методів аналізу в ІАЗ ОУВ.
2. `02_theme4_logic.png` — логіка Теми 4 за структурою курсу / репозиторію.
3. `03_methods_classification.png` — класифікація сучасних методів аналізу даних.
4. `04_statistical_methods.png` — статистичні методи аналізу.
5. `05_time_series_forecasting.png` — часові ряди та прогнозування.
6. `06_geospatial_fusion.png` — геопросторовий аналіз та multi-sensor fusion.
7. `07_clustering_anomaly_network.png` — кластеризація, виявлення аномалій та мережевий аналіз.
8. `08_deep_learning_cv.png` — Deep Learning та Computer Vision.
9. `09_nlp_llm_rag.png` — NLP, LLM та RAG для аналізу текстів.
10. `10_future_ai_methods.png` — Multimodal AI, XAI, RL та Human-in-the-Loop.

## Логіка комплекту

`місце Теми 4 → логіка курсу → taxonomy → класичні та спеціалізовані методи → сучасні AI-методи → перспективні AI-підходи`

Інтерактивна сторінка `interactive/lessons/theme4.html?lesson=t4-l1` показує ці рисунки у великому 16:9 viewer з навігацією 01–10, після чого слухач переходить до `Method Selector` та self-check.

> Рисунки є навчальними візуалізаціями із синтетичними/ілюстративними даними й не відображають реальну оперативну обстановку.
