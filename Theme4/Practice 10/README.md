# Тема 4. Заняття 10

## Практичне використання методів глибокого навчання в межах виконання індивідуальних (групових) проектів

### Навчальні питання

1. **Практичний аналіз даних в індивідуальних проектах з використанням методів глибокого навчання.**
2. **Практичний аналіз даних в групових проектах з використанням методів глибокого навчання.**

## Призначення каталогу

Цей каталог є первинним навчальним джерелом для заняття 4.10 і закриває попередній `source-gap` у Theme 4.

- `content.ipynb` — навчальний контент: постановка задачі, project contract, data protocol, baseline, архітектура, regularization, evaluation, error analysis, reproducibility, індивідуальна та групова організація роботи.
- `task.ipynb` — практичне завдання, варіанти проектів, обов'язкові artifacts, критерії оцінювання та peer-review checklist.
- `sample.ipynb` — відтворюваний приклад невеликого CNN-проекту на синтетичних 16×16 зображеннях. Інтернет і зовнішні datasets не потрібні.

## Методичний принцип

`problem → data/provenance → split → baseline → DL model → training/regularization → validation → error analysis → reproducible artifact → analytical conclusion`

Глибоке навчання не застосовується лише тому, що воно доступне. Слухач має обґрунтувати, чому DL доречне для конкретної задачі, порівняти його з простішим baseline і показати evidence того, що результат узагальнюється поза training data.

## Безпека даних

Навчальні приклади використовують synthetic/open data. Реальні чутливі або службові дані не повинні потрапляти до публічного GitHub, зовнішніх model hubs або сторонніх сервісів. Для реальних проектів необхідно дотримуватися чинних правил доступу, класифікації, зберігання та людського контролю.
