# mi2024-1

Навчальний репозиторій дисципліни з інформаційно-аналітичних технологій та військової аналітики.

Репозиторій містить наявні матеріали занять (Jupyter notebooks, дані, PDF, зображення та інші навчальні ресурси) і новий напрям **MI2024 Interactive** — набір інтерактивних web-сторінок для пояснення технологій, їх місця в аналітичному процесі та наслідків рішень аналітика.

## MI2024 Interactive

Перша версія свідомо використовує мінімальний стек:

- HTML5;
- modern CSS;
- Vanilla JavaScript (ES modules);
- JSON як формат опису контенту та сценаріїв;
- без React, Angular, Astro і без обов'язкового Node.js build step.

Основна ідея:

`аналітична проблема → місце технології в pipeline → інтерактивна дія → наслідок → аналітичний висновок`

### Локальний запуск

```bash
cd interactive
python3 -m http.server 8000
```

Після цього відкрити `http://localhost:8000`.

Не рекомендується відкривати HTML подвійним кліком через `file://`, оскільки ES modules і `fetch()` JSON-файлів надійніше працюють через локальний HTTP server.

## Принцип роботи з даними

Для інтерактивних прикладів використовувати синтетичні, навчальні або належним чином дозволені відкриті дані. Не розміщувати у web-шарі чутливі, службові або інші дані з обмеженим доступом.
