# OSINT Scraping Lab

Навчальна веблабораторія українською мовою. Без встановлення залежностей. Реальні GET-запити до навчальних HTML-сторінок, пошук вузлів DOM за CSS-селекторами, табличний перегляд, фільтрація, CSV/JSON і JSON-звіт із походженням даних.

## Локальний запуск

```bash
python3 -m http.server 8000 --directory dist
```

Відкрийте `http://localhost:8000`. Не відкривайте `index.html` безпосередньо через `file://`, бо режим отримання джерела потребує HTTP. Для метаданих SHA-256 використовується Web Crypto у безпечному контексті (HTTPS або localhost).

## Джерела

- `news.html`: 8 умовних інформаційних повідомлень;
- `register.html`: 7 умовних табличних записів;
- `links.html`: 6 прикладів посилань.

Всі навчальні дані синтетичні. Власні HTML-файли обробляються локально. URL-режим використовує прямий браузерний CORS-запит без cookies, без проксі та авторизації. Сайти, що не дозволяють доступ через CORS, не можуть бути опрацьовані в цьому режимі. Скрипт не виконує код зі сторінок, не вставляє отриману HTML-розмітку в інтерфейс і обмежує обсяг HTML до 2 МБ, а кількість записів до 500.

## Практикум

1. Відкрийте навчальну сторінку та перегляньте її HTML.
2. Отримайте джерело, застосуйте встановлені правила.
3. Змініть один із селекторів, оцініть вплив на кількість збігів або заповненість.
4. Знайдіть потрібні записи за категорією чи ключовим словом.
5. Перевірте їх за оригіналом, експортуйте CSV та JSON-звіт.

Вилучені дані не є автоматично перевіреними фактами. Використовуйте дозволені публічні джерела та враховуйте правила їх використання.
