# Розгортання OSINT Scraping Lab на Ubuntu

Проєкт не потребує бази даних, API-ключів, Node.js або встановлення Python-бібліотек. Вебсервер обслуговує статичні файли з `dist/`.

## 1. Найпростіший запуск для заняття

```bash
unzip OSINT-Scraping-Lab.zip
cd OSINT-Scraping-Lab
python3 -m http.server 8000 --directory dist --bind 127.0.0.1
```

Відкрити `http://localhost:8000/`. Сервер зупиняється через Ctrl+C. Для доступу з інших комп'ютерів у довіреній навчальній локальній мережі можна вказати `--bind 0.0.0.0`, після чого відкрити адресу сервера та порт 8000. Для SHA-256 з віддаленого комп'ютера рекомендовано HTTPS.

## 2. Docker Compose

За наявності Docker Engine та Compose:

```bash
cd OSINT-Scraping-Lab
docker compose up -d --build
docker compose ps
```

Відкрити `http://localhost:8080/` або `http://IP_СЕРВЕРА:8080/`. Зупинити:

```bash
docker compose down
```

## 3. Наявний Nginx

Скопіюйте вміст каталогу `dist/` в окремий document root на вашому вебсервері, наприклад `/var/www/osint-lab/`, і налаштуйте дозволений virtual host із `index index.html;`. Для публічного сервера використовуйте HTTPS, контроль доступу та відповідну політику мережі.

## 4. Перевірка

У браузері оберіть «Демо», натисніть «Отримати HTML», а далі «Вилучити дані». Очікувана кількість записів: інформаційний портал — 8, реєстр — 7, каталог — 6. Експортуйте CSV і JSON.

## 5. Важливо

- Відкривати через вебсервер, а не подвійним кліком по `index.html`.
- Для зовнішніх URL потрібен дозвіл CORS від джерела; для будь-якого HTML-файлу дозволений локальний імпорт.
- SHA-256 доступний у безпечному контексті браузера (HTTPS чи localhost).
- Поточна версія не має серверного scraping-проксі; вона не обходить обмеження сайтів, авторизацію або CAPTCHA.
- Навчальні джерела містять винятково синтетичні дані.
